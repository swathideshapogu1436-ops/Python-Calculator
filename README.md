# 🧮 Calculator Project

A simple **Calculator application using Python** that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Handles division by zero
- 🔢 Accepts decimal numbers
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used

- **Python**
- `input()`
- `float()`
- `if-elif-else`

## 💻 How It Works

The program:

1. Takes the first number from the user.
2. Takes an arithmetic operator (`+`, `-`, `*`, `/`).
3. Takes the second number.
4. Performs the selected operation.
5. Displays the result.
6. Checks whether the second number is zero before performing division.

## ▶️ Example

```text
Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5

Result: 50.0
```

### Division Example

```text
Enter first number: 10
Enter operator (+, -, *, /): /
Enter second number: 0

Cannot divide by zero
```
